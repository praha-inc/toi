# ガイド

toi は、命令的なダイアログやトーストを構築するための小さなヘッドレス React ユーティリティです。state やポータル、条件付きレンダリングを自分で組み立てる代わりに、コンポーネントを `await` するだけで、ユーザー(またはあなたのコード)がそのコンポーネントを使い終わったタイミングで解決します。

## はじめに

- [イントロダクション](./start/introduction) — toi の中心的な考え方と、各要素がどのように組み合わさるか。
- [クイックスタート](./start/quick) — toi をインストールして最初のコンポーネントをマウントする。

## 基本

- [ホストのマウント](./basic/mounting) — `toi` でマウントしたコンポーネントが実際にレンダリングされる場所。
- [解決する](./basic/resolving) — 値の有無による解決の違いと、終了アニメーションの扱い方。
- [再利用可能な関数](./basic/reusable-functions) — `toi.fn` でコンポーネントを一度だけ `toi` に紐づける。
- [追加の Props](./basic/additional-props) — `ref` と `resolve` 以外の Props を渡す方法。
